Este documento explica paso a paso cómo instalar, configurar y usar PPF desde cero,
incluido el soporte para temas de Oh My Posh y las funciones de Fase 3C (prompt
transitorio, tooltips y right prompt).

--------------------------------------------------------------------------------
1. REQUISITOS PREVIOS
--------------------------------------------------------------------------------

Antes de comenzar, asegúrate de tener instalado lo siguiente:

  - PowerShell 7.0 o superior (se recomienda 7.6 o posterior)
  - Git (para clonar el repositorio)
  - Una terminal compatible con ANSI truecolor y Nerd Font
    (recomendado: Windows Terminal, WezTerm, Alacritty, Kitty, iTerm2)
  - El instalador descarga e instala automáticamente JetBrainsMono Nerd Font
    (licencia SIL OFL, distribución libre permitida)

Verifica tu versión de PowerShell:

  pwsh --version

--------------------------------------------------------------------------------
2. PASO 1: CLONAR EL REPOSITORIO
--------------------------------------------------------------------------------

Abre PowerShell y ejecuta:

  git clone https://github.com/Pablitus666/PablitusPrompt.git
  cd PablitusPrompt

Esto descargará todo el código fuente, temas, ejemplos, pruebas y scripts.

--------------------------------------------------------------------------------
3. PASO 2: EJECUTAR EL INSTALADOR
--------------------------------------------------------------------------------

Desde la carpeta raíz del repositorio (D:\PablitusPrompt), ejecuta:

  .\Instalar-PPF.ps1

El instalador hará lo siguiente:

  - Creará la carpeta del módulo en:
        C:\Users\<TuUsuario>\Documents\PowerShell\Modules\PablitusPrompt
  - Copiará TODO el contenido de src/ al módulo
  - Copiará el núcleo .NET compilado a:
        ...\PablitusPrompt\dotnet\publish\PablitusPrompt.Core.dll
  - Listará los temas disponibles al finalizar

Salida esperada:

  ================================================
    Pablitus Prompt Framework - Instalación
  ================================================
  Copiando archivos del núcleo...
  Copiando núcleo .NET...
    PablitusPrompt.Core.deps.json
    PablitusPrompt.Core.dll
    PablitusPrompt.Core.pdb
  ================================================
    INSTALACIÓN COMPLETADA
  ================================================

Nota: Si el instalador advierte que no encontró dotnet/publish, compila primero el
núcleo .NET con:

  dotnet build dotnet/src/PablitusPrompt.Cli -c Release

--------------------------------------------------------------------------------
3.5. PASO 2B: INSTALACIÓN EN macOS Y LINUX
--------------------------------------------------------------------------------

En macOS y Linux, el instalador funciona de forma similar pero con rutas
específicas de cada sistema:

  cd PablitusPrompt
  pwsh ./Instalar-PPF.ps1

El instalador detectará automáticamente el sistema operativo y:

  - macOS: instalará JetBrainsMono Nerd Font en ~/Library/Fonts/
  - Linux: instalará JetBrainsMono Nerd Font en ~/.local/share/fonts/
    y ejecutará fc-cache para actualizar el caché de fuentes

Después de la instalación, selecciona 'JetBrainsMono Nerd Font' en la
configuración de tu terminal (iTerm2, Terminal, Alacritty, Kitty, etc.).

--------------------------------------------------------------------------------
4. PASO 3: IMPORTAR EL MÓDULO Y VERIFICAR
--------------------------------------------------------------------------------

En una nueva sesión de PowerShell (o en la misma):

  Import-Module PablitusPrompt -Force

Verifica que los temas estén disponibles:

  Get-PromptThemes | Select-Object Name | Sort-Object Name | Format-Table -AutoSize

Deberías ver una lista con temas como:
  - Default, Nord, Dracula, Kali, Catppuccin, Pablitus, Pablitus Stack, etc.

Cambia a un tema y prueba el prompt:

  Set-PromptTheme -Name "Pablitus Minimal"
  Get-PromptString -TerminalWidth 100 -NoColor

Ejemplo de salida esperada:

    Pablo   D:\PablitusPrompt   main   11:24 

--------------------------------------------------------------------------------
5. PASO 4: CONFIGURAR EL PROMPT EN TU PERFIL ($PROFILE)
--------------------------------------------------------------------------------

Para que PPF se cargue automáticamente cada vez que abras PowerShell, edita tu
perfil de PowerShell:

  notepad $PROFILE

O con Visual Studio Code:

  code $PROFILE

Agrega el siguiente bloque al final del archivo (ajusta la ruta si clonaste en
otra ubicación):

  # ==========================================
  # Pablitus Prompt Framework
  # ==========================================
  $PPF = "D:\PablitusPrompt\src"

  if (Test-Path (Join-Path $PPF "Bootstrap.ps1")) {
      try {
          . (Join-Path $PPF "Bootstrap.ps1")

          $env:PPF_USE_DOTNET_CORE = "1"
          Set-PromptTheme -Name "Pablitus Minimal"
          $global:PPF_SkipHiddenProviders = $true

          function global:prompt {
              try {
                  $context = Invoke-Prompt
                  Get-PromptString -Context $context -Renderer "PowerLine"
              }
              catch {
                  "PS $($executionContext.SessionState.Path.CurrentLocation)$('>' * ($nestedPromptLevel + 1)) "
              }
          }
      }
      catch {
          Write-Warning "[PPF] No se pudo cargar el prompt: $_"
      }
  }

Guarda el archivo, cierra y vuelve a abrir PowerShell. El tema se cargará solo.

--------------------------------------------------------------------------------
6. PASO 5: PERSISTENCIA AUTOMÁTICA DE TEMA (OPCIONAL)
--------------------------------------------------------------------------------

PPF incluye una función para guardar tu tema favorito y restaurarlo
automáticamente al iniciar cada sesión:

  # Guardar un tema PPF nativo
  Set-PromptThemePersist -ThemeName "Pablitus Minimal"

  # Guardar un tema de Oh My Posh (.NET core)
  Set-PromptThemePersist -DotNetThemePath "D:\PablitusPrompt\Temas oh my posh\cobalt2.omp.json"

  # Guardar ambos a la vez
  Set-PromptThemePersist -ThemeName "Pablitus Minimal" -DotNetThemePath "D:\PablitusPrompt\Temas oh my posh\cobalt2.omp.json"

La preferencia se guarda en:
  C:\Users\<TuUsuario>\ppf-theme-pref.json

Al abrir PowerShell, el perfil restaurará automáticamente el último tema guardado
sin mostrar mensajes adicionales.

--------------------------------------------------------------------------------
7. FASE 3C: PROMPT TRANSITORIO, TOOLTIPS Y RIGHT PROMPT (.NET CORE)
--------------------------------------------------------------------------------

Estas funciones avanzadas requieren el núcleo .NET de PPF (modo opt-in).

7.1 Activar el núcleo .NET

  $env:PPF_USE_DOTNET_CORE = "1"
  Enable-PPFDotNetCore -ThemePath "D:\PablitusPrompt\examples\dotnet\theme.pablitusminimal.ppf.json"

Verifica el estado:

  Get-PPFDotNetCoreStatus

Deberías ver:
  Enabled           : True
  AssemblyLoaded    : True
  EngineReady       : True
  Available         : True

7.2 Usar las funciones de Fase 3C

  # Prompt principal con right prompt (si el tema lo define)
  Get-PromptString -TerminalWidth 120 -NoColor

  # Prompt transitorio (se muestra tras aceptar un comando)
  Get-PromptString -Transient -TerminalWidth 120 -NoColor

  # Tooltip para un comando específico
  Get-PromptTooltip -Command "git" -TerminalWidth 120 -Column 5 -NoColor

Desactiva el núcleo .NET cuando ya no lo necesites:

  Disable-PPFDotNetCore
  Remove-Item Env:\PPF_USE_DOTNET_CORE -ErrorAction SilentlyContinue

--------------------------------------------------------------------------------
8. TEMAS DE OH MY POSH (OMP)
--------------------------------------------------------------------------------

PPF puede importar y usar temas oficiales de Oh My Posh a través de su núcleo .NET.

8.1 Descargar todos los temas de Oh My Posh (recomendado)

Ejecuta esto desde la raíz del repositorio:

  $temasOmp = "D:\PablitusPrompt\Temas oh my posh"
  if (-not (Test-Path -LiteralPath $temasOmp)) {
      $null = New-Item -ItemType Directory -Path $temasOmp -Force
  }
  $temp = Join-Path $env:TEMP "oh-my-posh-temp"
  Remove-Item -Path $temp -Recurse -Force -ErrorAction SilentlyContinue
  git clone --depth 1 https://github.com/JanDeDobbeleer/oh-my-posh.git $temp
  Copy-Item -Path (Join-Path $temp "themes\*") -Destination $temasOmp -Recurse -Force
  Remove-Item -Path $temp -Recurse -Force

  Write-Host "Temas descargados: $(Get-ChildItem -Path "$temasOmp\*.omp.json" | Measure-Object).Count" -ForegroundColor Green

Esto descarga los 123 temas oficiales de Oh My Posh a tu carpeta local.

8.2 Importar y activar un tema de Oh My Posh

  Import-Module PablitusPrompt -Force
  $env:PPF_USE_DOTNET_CORE = "1"

  Import-PPFDotNetTheme -Path "D:\PablitusPrompt\Temas oh my posh\cobalt2.omp.json" -Activate -IgnoreUnsupported
  Get-PromptString -TerminalWidth 120 -NoColor

Parámetros de Import-PPFDotNetTheme:
  -Path            Ruta al archivo .omp.json (obligatorio)
  -Activate        Importa y activa el tema en un solo paso
  -IgnoreUnsupported Salta segmentos no soportados en lugar de fallar

Segmentos de Oh My Posh soportados por PPF (.NET core):
  session, path, git, text, time, exit,
  aws, az, azure, azd, az_functions, gcp, firebase,
  battery, cmd_duration,
  docker, docker_context,
  dotnet,
  gitcommit, gitversion,
  go, golang,
  helm, kubernetes, kubectl,
  node, npm, npx, pnpm, yarn, bun, deno,
  python,
  terraform, terraform_required_version,
  gradle, mvn, mvnw,
  ruby, rust, cargo,
  php, composer,
  swift, kotlin, scala

Total: 46 tipos de segmento soportados (6 built-in + 40 de Oh My Posh).

Nota: Aunque PPF soporta estos tipos de segmento, algunos dependen de
herramientas externas que pueden no estar instaladas en tu sistema
(kubectl, aws, docker, terraform, etc.). Si una herramienta no está
disponible, el segmento se omite silenciosamente y el prompt sigue
renderizándose con los segmentos que sí estén disponibles.

Para importar temas que usen segmentos no listados arriba, usa el parámetro
-IgnoreUnsupported para saltarlos en lugar de fallar.

9. COMANDOS RÁPIDOS DE REFERENCIA
--------------------------------------------------------------------------------

  Import-Module PablitusPrompt -Force          # Cargar el módulo

  Set-PromptThemePersist ...                   # Guardar tema persistente

10. SOLUCIÓN DE PROBLEMAS COMUNES
--------------------------------------------------------------------------------

10.1 "PPF .NET core assembly not found"
     Causa: El instalador no copió la DLL o la ruta es incorrecta.
     Solución: Vuelve a ejecutar .\Instalar-PPF.ps1 o define la variable:
       $env:PPF_DOTNET_CORE_DLL = "C:\ruta\completa\PablitusPrompt.Core.dll"

10.2 El tema de Oh My Posh falla al importar
     Causa: Segmentos no soportados.
     Solución: Agrega -IgnoreUnsupported al comando Import-PPFDotNetTheme.

10.3 El prompt no aparece al abrir PowerShell
     Causa: El perfil no cargó el módulo.
     Solución: Verifica que $PROFILE contenga el bloque de configuración y que
              la ruta $PPF apunte a la carpeta src correcta.

10.4 Glifos se ven como cuadros o signos de interrogación
     Causa: La Nerd Font no está instalada o no está seleccionada en la terminal.
     Solución: El instalador ya descarga e instala JetBrainsMono Nerd Font
              automáticamente. Si persiste el problema, reinicia tu terminal
              y selecciona 'JetBrainsMono Nerd Font' en la configuración
              de tu terminal.

10.5 "Cannot find path 'ruta\al\tema.omp.json'"
     Causa: La ruta del tema no existe.
     Solución: Usa una ruta real, por ejemplo:
       D:\PablitusPrompt\Temas oh my posh\cobalt2.omp.json

--------------------------------------------------------------------------------
11. ¿SE GENERA UN .EXE?
--------------------------------------------------------------------------------

NO. PPF es un módulo de PowerShell, no una aplicación independiente. No se genera
ni se necesita un archivo .exe. Todo se ejecuta dentro de PowerShell 7+ mediante
los comandos del módulo.

13. SOPORTE MULTI-SHELL (bash, zsh, fish, cmd)
----------------------------------------------------------------------------

PPF es un módulo de PowerShell nativo, pero incluye scripts de inicialización
en src/ShellInit/ que permiten usarlo desde otros shells invocando a pwsh:

  | Archivo     | Shell  | Uso                                                  |
  |-------------|--------|------------------------------------------------------|
  | ppf.bash    | bash   | source /ruta/a/ppf.bash en ~/.bashrc                 |
  | ppf.zsh     | zsh    | source /ruta/a/ppf.zsh en ~/.zshrc                   |
  | ppf.fish    | fish   | source /ruta/a/ppf.fish en ~/.config/fish/config.fish |
  | ppf.cmd     | cmd    | Llamar desde un macro o AutoRun                      |
  | ppf.ps1     | PowerShell | Importar directamente en PowerShell 7+            |

Ejemplo para bash (~/.bashrc):

  source /ruta/a/PablitusPrompt/src/ShellInit/ppf.bash

Ejemplo para zsh (~/.zshrc):

  source /ruta/a/PablitusPrompt/src/ShellInit/ppf.zsh

Nota: iniciar pwsh en cada prompt añade un coste de arranque; para uso
diario se recomienda usar PPF directamente desde PowerShell 7+.
